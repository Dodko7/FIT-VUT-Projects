# Moore Machine Debugger, Runner, and Editor
FIT BUT, 2025

## Overview
This project implements a Moore machine debugger, runner, and editor with a GUI using C++17 and Qt.

This repository has been made public for academic purposes. Using this code as your solution to the project could result in disciplinary action(s) and further issues. It is prohibited to use any part of this code in your own academic projects.

## Directory Structure
- `src/`: Source code for the core FSM logic and GUI.
- `tests/`: Unit tests for the FSM.
- `doc/`: Documentation files.
